# RSNA Vibe Coding Hackathon
Got an idea for an app that could improve radiology? New AI coding tools make it easy for expert programmers  and non-programmers alike to use their domain knowledge to “vibe code” ideas into solutions. RSNA is holding its Inaugural Vibe Coding Hackathon at this year’s annual meeting where you can team with like-minded imaging professionals to explore the expanding world of vibe coding. Bring your favorite AI coding agent or just a burning problem to be solved.
Check out [RSNA 2026 Vibe Coding Hackathon](https://www.rsna.org/artificial-intelligence/at-the-meeting/vibe-coding-hackathon) to learn more.

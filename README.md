# RSNA Vibe Coding Hackathon
Got an idea for an app that could improve radiology? New AI coding tools make it easy for expert programmers  and non-programmers alike to use their domain knowledge to “vibe code” ideas into solutions. RSNA is holding its Inaugural Vibe Coding Hackathon at this year’s annual meeting where you can team with like-minded imaging professionals to explore the expanding world of vibe coding. Bring your favorite AI coding agent or just a burning problem to be solved. RSNA will provide access to resources and sample data to help you transform your vision into a working prototype. 

Participating teams will submit a video, github repo, and an optional demo. Judges will announce awards at a special event during RSNA. Earn recognition for your work at the world’s largest forum for the medical imaging community. 

Keep coming back to this repo for more updates about the Hackathon!
